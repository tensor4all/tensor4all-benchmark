# Omitted factor point

An exploratory N=8, factor-rtol `3e-5` input-only command completed input construction but exited before direct-product materialization because its sampled factor error exceeded the existing `1e-4` sanity gate. It produced no JSON result and is omitted from the bounded matrix. The tighter N=8 points at `1e-5` and `1e-6` pass the same gate and are retained.
